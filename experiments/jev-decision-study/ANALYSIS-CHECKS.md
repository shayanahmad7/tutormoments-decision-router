# Analysis checks

This is a prediction experiment against a released reference, not a classroom treatment study. Automated correctness is exact label agreement. No new model judges or human validation are claimed.

| Check | Treatment |
|---|---|
| Aggregation hides subgroup changes | Report scaffold and rigor recall; the selected prompt trades fewer missed rigor opportunities for more missed scaffold needs. |
| Ecological inference | No individual learning outcome or classroom benefit inferred. |
| Selection bias | Teacher-selected, balanced source; prior benchmark exposure disclosed. |
| Collider adjustment | Primary result retains all records; conflict/unique-context sensitivity is separately named. |
| Base rates | 260/260 overall; development is 51 scaffold/87 rigor, evaluation 209/173. Select using balanced accuracy, not majority-class accuracy. |
| Regression to the mean | Fresh prior-prompt control and unchanged repeats; never select the best repeat. |
| Multiple comparisons | Five development candidates, one frozen winner; secondary threshold and repeat checks explicitly exploratory. No significance hunt. |
| P-value and interval interpretation | Student-cluster uncertainty intervals describe this internal comparison, not proof of equivalence or generalization. No independent-moment significance test ignores student clustering. |
| Causal interpretation | Claims concern prompt-associated label agreement, not student learning or human-tutor superiority. |
| Pseudoreplication | 89 students, 491 unique contexts; repeat calls and repeated records are not extra independent students. |
| Researcher degrees of freedom | Prompts frozen, selection precedes evaluation; threshold amendment and replication decision timestamped; source disagreements never repaired to raise scores. |

All-520 accuracy includes the development cases and is descriptive. The primary evaluation uses the other 71 students. Prior corpus exposure and the small number of development students limit the interpretation of either result.
